# Support

English | [简体中文](SUPPORT_zh-CN.md)

For usage questions, configuration problems, and feature requests, open a GitHub issue and include a redacted configuration, versions, logs, and reproduction steps.

Do not report security vulnerabilities publicly. Use the private reporting channel described in [SECURITY.md](SECURITY.md).

This project is maintained by the community on a best-effort basis and does not provide an SLA or production-availability guarantee.
